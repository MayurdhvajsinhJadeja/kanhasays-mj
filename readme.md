# KãnhãSays 🦚

A Streamlit-based AI chatbot that gives divine insights from the Bhagavad Gita.

## Features
- Ask real-life questions and get relevant Gita verses
- Semantic matching powered by ML
- Beautiful Krishna-themed UI

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
